# 서울 테마 추가 내역

기존 147개 → 216개. 신규 69개, 기존 7개 정보 보완. 신규 매장 16곳.

지역별: 홍대 121개, 강남 57개, 건대 38개.

## 반영 기준

- 공식 사이트의 테마 이름·장르·난이도·시간·인원만 반영. 출처는 theme-source-audit.json과 각 테마의 공식 사이트 링크에서 확인.
- 시놉시스·포스터는 앱에 복제하지 않음.
- 공포 강도, 표기 없는 시간과 인원을 추측하지 않음. 머더파커의 문자 난이도와 작은창고의 3+2는 숫자로 임의 환산하지 않음.
- 매장 위치는 기존 카카오 장소 목록을 사용. 좌표의 최신성은 별도 확인 필요.
- 기존 테마 ID와 이용 기록을 보존하며 테마를 삭제하거나 폐점 처리하지 않음. 전체 기존 정보의 최신성은 미검증.
- 이번에 앱의 체험 데이터에 반영. Supabase 운영 DB에는 sql/6-seoul-expansion.sql을 별도로 실행해야 함.

## 아직 남은 범위

서울 전체 목록은 아님. 제로월드, 황금열쇠, 엑스케이프 등 이번 반영에 포함되지 않은 브랜드와 신규 지점이 남아 있음. 공식 페이지에서 확인하지 못한 테마는 만들지 않음.
